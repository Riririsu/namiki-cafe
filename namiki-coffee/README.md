# namiki-coffee WordPressテーマ 導入手順

## 1. テーマの設置
`namiki-coffee` フォルダごと `wp-content/themes/` にアップロードし、
管理画面「外観 > テーマ」から有効化してください。

## 2. 画像の設置
元コーディングの `img/` フォルダの中身を、すべて
`wp-content/themes/namiki-coffee/assets/img/` にコピーしてください。
（ロゴ、favicon、MVスライダー、ギャラリー画像などすべてこの中に入ります）

## 3. 固定ページを2つ作成
管理画面「固定ページ > 新規追加」で以下を作成します（本文は空でOK）。
- 「トップページ」（本サイトのホーム用）
- 「お知らせ」（NEWS一覧用）

## 4. 表示設定
「設定 > 表示設定」で、
- ホームページの表示：「固定ページ」を選択
- ホームページ：「トップページ」
- 投稿ページ：「お知らせ」

に設定してください。これで
- トップページ → `front-page.php`（index.htmlのデザイン）
- お知らせ一覧 → `home.php`（news.htmlのデザイン）
- お知らせ詳細 → `single.php`（single.htmlのデザイン）

が自動的に使われます。

## 5. パーマリンク設定
「設定 > パーマリンク設定」で「投稿名」を選択することをおすすめします。

## 6. NEWS投稿の作成
「投稿 > 新規追加」でお知らせを作成してください。
- カテゴリー：「メニュー」「お知らせ」など、コーディングにあった表記でカテゴリーを作成して割り当てると、一覧・詳細ページに反映されます（カテゴリー未設定の場合は自動で「お知らせ」と表示されます）。
- アイキャッチ画像：single.htmlの写真部分に反映されます（未設定の場合は写真エリアごと非表示になります）。
- 本文：`the_content()` で出力されるので、通常のブロックエディタでそのまま執筆できます。

## 7. グローバルナビゲーションについて（任意）
何もしなくても、header.php はコーディング通りの固定メニュー（CONCEPT/MENU/NEWS/ABOUT/SHOP INFO/CONTACT/Instagram）を自動表示します。
管理画面「外観 > メニュー」でメニューを作成し、表示位置に「グローバルナビゲーション」を割り当てると、そちらが優先されます（項目の並べ替えや追加をノーコードで行いたい場合に利用してください）。

## 8. その他おまかせで対応した点
- コピーライトの年は `date('Y')` で自動的に今年になります。
- Google Map・Instagram・電話番号は、現状コーディングと同じ固定値のままHTMLに残しています。今後コロコロ変える予定があれば、カスタマイザーやACFのテキストフィールド化も追加できるのでお知らせください。
- `main.js` はそのまま `assets/js/main.js` に配置しているだけで、改修はしていません（ハンバーガーメニュー・MVスライダー・タブ・ギャラリー無限スクロール・ヘッダー追従、すべて元のまま動作します）。

## ファイル構成
```
namiki-coffee/
├── style.css          … テーマ情報（WordPress必須ファイル）
├── functions.php       … スタイル/スクリプト読み込み、各種ヘルパー関数
├── header.php           … 共通ヘッダー
├── footer.php           … 共通フッター
├── front-page.php       … トップページ（index.html）
├── home.php              … NEWS一覧（news.html）
├── single.php            … NEWS詳細（single.html）
├── index.php              … WordPress必須のフォールバック
├── page.php               … その他の固定ページ用フォールバック
└── assets/
    ├── css/reset.css
    ├── css/main.css
    ├── js/main.js
    └── img/            … ここに画像を設置
```
